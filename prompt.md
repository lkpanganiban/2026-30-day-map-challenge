# Prompts used

A verbatim, in-order export of the user prompts that produced this project.
Harness/system instructions, tool output and plan-mode notices are not included.

---

## 1. Initial brief (plan mode)

> I am participating in the 30 day map challenge for 2026. I want to create a map using python for all of the days. Use openstreetmap data within the philippines, you can also include data from sentinel 2 and landsat 9. I want the maps to have a good story about the recent events in the Philippines.

## 2. Execute the plan (build mode)

> execute the plan above

## 3. Day 7 (build mode - step 2 skipped day 7 hence the need to force the model to generate or buildout the day 7)

> do day 7 to the best of your capabilities

## 4. Day 7 refinement (build mode)

> can we refine day 7 such that it will be finer than just the 250m?

## 5. Build all remaining days (build mode)

> continue to all the days

## 6. Per-day documentation (build mode)

> create an individual README.md for each day, telling the data, process and story. be as verbose as possible.

## 7. Static gallery site (build mode)

> create a static html file that can be loaded and hosted in github, the html file will host the map images as well as the descriptions. there will be a main dashboard showing a gallery of the maps. and once clicked it will be directed to the contents of the readme.md of each map. the gallery dashboard will contain a short description of the map based on the readme.md.

## 8. Interactive thumbnails (build mode)

> the interactive map does not have a good thumbnail in the gallery dashboard. provide a fix for this.

## 9. Data links (build mode)

> include the links and sources to the data (not local)

## 10. Main README polish (build mode)

> update the main README.md to include some writeups about the 30 day map challenge and add some icons and graphics to make the README.md "look pretty" in the github repo.

## 11. GitHub Pages (build mode)

> make the repo available via github pages
